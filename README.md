## Featured Projects

### IoT Smart Parking System
A smart parking and vehicle access monitoring project built using ESP32-CAM, sensors, Python Flask, SQL, and OpenCV. The system focuses on detecting vehicles, monitoring parking slot availability, and managing access through a simple dashboard approach for practical usage.

- Core technologies: ESP32-CAM, Python, Flask, SQL, OpenCV
- Purpose: vehicle access handling and parking-slot monitoring
- Project style: IoT + embedded + backend + monitoring dashboard

### Shop2Business
A web platform focused on helping commercial workflows become more organized and business-friendly. The project is available as a live demo and showcases a practical application of frontend development and UI design.

- Live Demo: [Shop2Business](https://shop2bussiness.netlify.app/)
- Focus: web platform experience and responsive interface

### To-Do Task Application
A task management application built with React, TypeScript, Vite, and Tailwind CSS. The app emphasizes straightforward task management, a clean interface, and a smooth user experience for daily productivity.

- Technologies: React, TypeScript, Vite, Tailwind CSS
- Focus: task creation, organization, and manageability

### Smart Water Quality Monitoring
A monitoring system designed around ESP32 and Arduino-based hardware to track water quality using sensor inputs. The project aims to provide a practical solution for monitoring essential environmental parameters in a simple and efficient way.

- Technologies: ESP32, Arduino, sensors
- Purpose: water-quality monitoring and environmental insight
